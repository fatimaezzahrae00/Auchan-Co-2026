1-C'est quoi Fetch()
C une fonction en JavaScript integrée qui permet d'envoyer des requêtes HTTP (GET, POST, etc.) et de récupérer des données depuis une URL


 1.2 -modules ES6 (import / export)
    export : Permet de rendre une fonction ou variable disponible pour d’autres fichiers.
    import : Permet de récupérer ce qui a été exporté.


2- C'est quoi map()
     La méthode map() en JavaScript permet de créer un nouveau tableau en appliquant une fonction donnée à chaque élément d'un tableau existant. Elle ne modifie pas le tableau d'origine.

3-c'est quoi ForEach 
 c'est une méthode  en JavaScript permet d'exécuter une fonction donnée une fois pour chaque élément d'un tableau. Elle est couramment utilisée pour parcourir des tableaux.
